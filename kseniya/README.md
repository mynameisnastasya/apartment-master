# Квартира Ксении

Самостоятельная страница /kseniya.html. Не добавлять ссылки на неё в страницы Лизы и не импортировать данные или сцены Лизы. Это отдельная квартира по пользовательской планировке.

## Варианты

По умолчанию открывается вариант «Трёшка 02»: две изолированные спальни + компактная кухня-гостиная. Большая спальня остаётся 13,10 м². Вторая спальня занимает примерно 7,7 м² у окна. Вдоль неё сохраняется проход около 98 см. Кухня объединяется с общей зоной через новый широкий проём; суммарная площадь общей зоны около 14,3 м².

Вариант «Трёшка 01» сохранён для сравнения: две спальни с окнами + отдельная, но проходная гостиная. «Исходный план» показывает квартиру без новых перегородок.

Размеры проёмов и их положения приблизительные. Исходное изображение не замыкает размерные цепочки; приоритет отдан габаритам жилых комнат, кухни и коридора. Стены 12 см и высота 2,7 м — допущения.

Критичное допущение варианта 02: новая перегородка второй спальни попадает в зону большого окна. Перед реализацией её надо привязать к фактическому оконному импосту или корректировать оконный блок. Расширение проёма между кухней и общей зоной возможно только после проверки конструкции стены. Мокрые зоны не перенесены.

Страница использует Three.js 0.185.1 как ES-модуль с jsDelivr через import map. Исходники находятся в kseniya/app.js и kseniya/model.js. Старый kseniya/viewer.js оставлен как исторический артефакт и страницей больше не загружается.

Проверка браузером:

    npm start
    node kseniya/verify.mjs

Открыть http://127.0.0.1:4173/kseniya.html.
