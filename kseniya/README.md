# Квартира Ксении

Самостоятельная страница `/kseniya.html`. Не добавлять ссылки на неё в страницы Лизы и не импортировать данные или сцены Лизы. Это отдельная квартира по изображению пользователя.

Модель в метрах: зал 3.04 × 5.56, нижняя комната 2.34 × 5.60, кухня 2.52 × 2.04. Размеры проёмов и их положения приблизительные. Исходное изображение не замыкает размерные цепочки; приоритет отдан габаритам жилых комнат, кухни и ширине коридора 0.86 м. Стены 0.12 м и высота 2.7 м — допущения.

Новый вариант: две спальни с окнами + проходная гостиная без своего окна; это не полноценная изолированная трёхкомнатная квартира. Перегородка в зале требует проверки конструкций и согласуемости. Остекление даёт только заимствованный свет. Мокрые зоны не перенесены.

Сборка независимого просмотрщика (не запускает генератор Лизы):

```sh
npx esbuild kseniya/app.js --bundle --minify --format=iife --outfile=kseniya/viewer.js
npm start
```

Открыть http://127.0.0.1:4173/kseniya.html. Файл viewer.js хранится в git для статического GitHub Pages. Исходный 2D и новый 2D/3D используют одну геометрию. Для проверки: `node kseniya/verify.mjs` при запущенном npm start.

Страница без навигации на другие проекты и с noindex. Это не аутентификация; весь репозиторий публичен.
