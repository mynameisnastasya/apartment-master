# PBR textures

The files are unmodified 1K JPEG material maps, downloaded from Poly Haven and verified against the MD5 values in its asset API. They are served from this repository; the viewer does not depend on the texture provider at runtime.

All three assets are published under [CC0](https://polyhaven.com/license).

| Asset | Files used | Author / source |
| --- | --- | --- |
| Wood Floor | `wood_floor_diff_1k.jpg`, `wood_floor_nor_gl_1k.jpg` | Dimitrios Savva — https://polyhaven.com/a/wood_floor |
| Wood Table 001 | `wood_table_001_diff_1k.jpg`, `wood_table_001_nor_gl_1k.jpg` | Dimitrios Savva, Rico Cilliers — https://polyhaven.com/a/wood_table_001 |
| Rough Linen | `rough_linen_nor_gl_1k.jpg` | colormass, Rico Cilliers — https://polyhaven.com/a/rough_linen |

Colour maps use sRGB; normal maps use linear data. Fabric colour, stone and plaster are generated locally. The linen normal map supplies the weave independently from the chosen fabric colour.
