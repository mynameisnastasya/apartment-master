# Елена — дом для двоих

[Открыть проект](https://mynameisnastasya.github.io/apartment-master/elena.html). Пять вариантов для пары без детей; прежние восемь схем сохранены только в истории Git.

Актуальная редакция 25.10.2026 уменьшает количество высоких шкафов, распределяет хранение по назначению и проверяет пространство для действий. Исследованные рекомендации, источники, изменения по вариантам и ограничения описаны в [design-review.md](design-review.md).

## Варианты

1. **Спальня за стеклом:** шкаф в прихожей, низкий комод 120 см, кровать 160 × 200, диван и кабинет на балконе.
2. **Свободный план:** без новых перегородок и высоких шкафов в комнате; комод 80 см, кровать, диван, рабочее место у окна.
3. **Личный сюит:** гардеробная 150 см и шкаф прихожей; кровать 180 × 200 без дублирующего шкафа у изножья, диван для чтения на балконе.
4. **Два рабочих места:** два стола по 120 × 65 см на тёплом балконе; шкаф в прихожей и низкий комод в комнате. Рабочая зона общая, без изоляции звонков.
5. **Кухня-гостиная:** условный проём, северная спальная зона за стеклом; одежда в прихожей, бельё под кроватью. Меньший запас хранения.

Во всех вариантах предусмотрены подъёмные кровати и небольшая открытая ниша для повседневных курток. Размер шкафа 150 × 68 × 236 см — плановый габарит с запасом под фасады, не обещание точного совпадения с конкретным изделием.

## Геометрия и границы достоверности

Источник — `source.jpeg`. Площади 17,9 / 9,1 / 9,4 / 3,3 / 5,4 м² взяты с фото, а не вычислены по обмеру. Модель использует приблизительный контур и высоту потолка 2,6 м. Балкон принят тёплым по данным заказчика. Варианты 01–04 сохраняют существующие стены; проём 05 допустим только после обследования. Коридор к санузлу около 53 см требует первоочередного обмера. Это эскиз, не рабочие чертежи и не подтверждение норм.

2D и 3D используют `data.js`. `ergonomics.js` вычисляет зоны действий и размеры; высота предметов не используется как разрешение ставить мебель друг на друга. `storagePlan()` описывает назначение хранения без выдуманной вместимости в количестве вещей.

## Живая 3D-модель

`realistic-scene.js`: Three.js, физические материалы, мягкая мебель, сканированные CC0-текстуры, солнце и площадной свет, контактные тени, сглаживание и ACES. Источники карт — `textures/README.md`, лицензия библиотеки — `THIRD_PARTY_LICENSES.txt`.

Камеры: общий вид, спальня, хранение, кухня, балкон. Модель загружается по запросу; первый экран — размерный план. «Материалы» содержит прежние атмосферные изображения, которые не заменяют актуальную расстановку. Новый ракурс «Хранение» показывает стену напротив кровати или шкаф прихожей.

Накопительная трассировка полностью удалена. Параметр `quality=high` игнорируется и очищается. Кадры рисуются только по событиям; скрытая вкладка, фото/план и покой не запускают постоянный рендер. Геометрии освобождаются при пересборке, материалы переиспользуются; переход между интерьерными камерами не пересоздаёт мебель.

## Проверка

```sh
npm ci
node elena/qa.mjs
node elena/ergonomics-qa.mjs
node elena/build.mjs
npx playwright install chromium
node elena/verify.mjs
```

Проверяются пять вариантов, габариты мебели, пересечения, открывание дверей и техники, выдвинутые ящики с местом для человека, два подхода к кроватям и связность маршрутов. Сетка 25 мм, условное тело 60 см; к санузлу отдельно проверяется лишь 50 см с явно указанным ограничением. Тесты также подтверждают отсутствие высоких шкафов у кроватей, количество гардеробов, высоту комодов, рабочую поверхность кухни и две зоны рабочих кресел.

Браузерная проверка: все планы/сцены/референсы, выбор мебели, пять ракурсов, дневной и вечерний свет, SVG, мобильные 390 px, старые ссылки, запасной 2D, отсутствие фоновых кадров и утечек геометрий. Скриншоты — `test-results/elena/`; CI публикует их как `elena-five-couple-layouts`.
