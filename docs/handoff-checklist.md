## Шаг 1. Привязка к реальной квартире — обязательно

- [ ] Заказать контрольный обмер: все стены, диагонали, чистые проёмы, высоты потолков, перепады пола.
- [ ] Уточнить несущие элементы, материал стен и правовой статус любой предполагаемой перепланировки. Не считать линии в 3D разрешением на демонтаж.
- [ ] Зафиксировать окна, радиаторы, открывание створок, подоконники и выступающие элементы.
- [ ] Определить фактическое положение стояков, канализационных выпусков, вентиляционных каналов и доступ к ревизиям.
- [ ] Для Елены отдельно установить назначение заштрихованной зоны у санузла, положение его двери, возможность укорачивания перегородки бывшей ниши и допустимость проёма варианта 05.
- [ ] Для Лизы сверить размерные цепочки референсов L/M с обмером; не переносить в строительные планы приблизительные площади и габариты.

**Выход шага:** датированный обмерный план с фотографиями, актом обследования спорных конструкций и перечнем допустимых изменений. До него не заказывать встроенную мебель и каменные детали в окончательный размер.

## Шаг 2. Выбрать один вариант и зафиксировать компромиссы

- [ ] Зафиксировать выбранный вариант, дату согласования и ответственного за решения; не смешивать геометрию разных эскизов.
- [ ] Пройти реальные маршруты с рулеткой: вход, санузел, подходы к кроватям и шкафам, открытые двери, выдвинутые ящики и бытовая техника.
- [ ] Для Елены собрать список одежды и домашних вещей пары, проверить вместимость, монтаж, доступ и пути доставки. Два рабочих места варианта 04 не обеспечивают звукоизоляцию.
- [ ] Согласовать реальную кухонную и сантехническую технику по паспортам: дверцы, люки, зазоры, доступ к коммуникациям.
- [ ] Утвердить материалы по физическим образцам и пробам освещения, а не только по изображению или 3D.

**Выход шага:** утверждённый обмерный вариант планировки, ведомость решений/компромиссов, актуальная мебельная спецификация. Для Лизы отметка об утверждении D / 01 **не является** автоматическим утверждением вариантов L–O.

## Шаг 3. Инженерия и согласования

- [ ] Профильный специалист рассчитывает электрику по реальной выделенной мощности, группам, защите и паспортам оборудования.
- [ ] Сантехник/проектировщик проверяет трассы, уклоны, ревизии, вентиляцию, гидроизоляцию и условия подключения.
- [ ] Проверить отопление, вентиляцию, охлаждение, электропитание балкона и допустимость изменений ограждений.
- [ ] Подтвердить необходимые согласования перепланировки и ограничения здания с соответствующими специалистами и органами.
- [ ] Выпустить координированные рабочие чертежи и проверить пересечения мебели, труб, электрики, света и дверей.

**Выход шага:** согласованный рабочий комплект, а не только 3D-модель и предварительные схемы. [Инженерные ограничения Лизы](../engineering.html), [ограничения Елены](../elena/design-review.md).

## Шаг 4. Комплектация и контроль

- [ ] Сверить артикулы, цены и наличие товаров на дату закупки; подборки магазинов в проекте носят справочный характер.
- [ ] Уточнить допуски и монтажные зазоры встроенной мебели, дверей, столешниц и сантехники.
- [ ] Согласовать бюджет с резервом, этапы, ответственных, сроки и порядок приёмки скрытых работ.
- [ ] После обмера обновить цифровую геометрию, ведомости и рендеры; повторно запустить проверки.
- [ ] На объекте подтвердить соответствие исполнительных размеров и работающих инженерных систем документации.

## Техническая проверка репозитория

```sh
npm ci
npm run build
npm run qa
node scripts/client-qa.mjs
node elena/qa.mjs
node elena/ergonomics-qa.mjs
node elena/build.mjs
node elena/verify.mjs
```

Для браузерных проверок понадобится Chromium из Playwright; CI устанавливает его самостоятельно. Успешные тесты означают отсутствие обнаруженных программных регрессий, **не** снимают ограничения проектной геометрии и не заменяют инженерную экспертизу.
