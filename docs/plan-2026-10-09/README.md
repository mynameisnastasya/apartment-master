## Что уточнить перед стройкой

1. **Кухня.** Согласовать окончательную кухонную раскладку (раковина, варочная, посудомойка, холодильник, фартук): рабочие розетки нельзя ставить в непосредственной близости к воде и нагреву; подключение крупной техники размещать в обслуживаемой соседней секции, с доступом к отключению.
2. **Санузел.** A01–A05 — исключительно условные маркеры. Выбрать конкретные точки только после проверки зон ванны/душа, допускаемых электрических устройств и степени защиты; предусмотреть необходимую защиту УЗО/дифзащитой и заземление по действующим нормам. Не устанавливать механизмы у ванны на основании этого эскиза.
3. **Кондиционеры и ТВ.** Места B04/B05/B08, C08, L05/L06 являются резервами и должны быть согласованы с реальным размещением экрана, наружных блоков, трасс и дренажа.
4. **Детская.** Механизмы с защитными шторками, защита от доступа к проводам и креплениям, отсутствие открытых удлинителей рядом с кроватью.
5. **Гардероб.** Выделить доступный сервисный блок для подсветки, учесть дверцы и шкафные секции; не закрывать постоянно работающую технику без вентиляции.
6. **Электрощит.** Линии, сечения, автоматические выключатели, УЗО/дифзащита, уравнивание потенциалов, расчёт нагрузок и разделение приборов — отдельный проверяемый инженером проект, не выводить их из количества кружков.
7. **Электроплан из скриншота** и размещение света — сверить с этой новой меблировкой, не переносить точки автоматически: в старом комплекте D другая расстановка.

**Правило приоритетов:** исходные скриншоты заказчика → фактический обмер → согласованная кухонная/мебельная спецификация → окончательный ЭОМ. Эта схема только для выбора удобных мест.
