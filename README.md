# Квартира Лизы · пять планировок

[Смотреть альбом](https://mynameisnastasya.github.io/apartment-master/) · [Сравнить планы в 3D](https://mynameisnastasya.github.io/apartment-master/model.html) · [План D и размеры](https://mynameisnastasya.github.io/apartment-master/LIZA.html)

**D** — исходная доработанная планировка: две комнаты у окон, центральная ванная, кухня слева, диагональная перегородка. **E–H** — ещё четыре расстановки мебели на том же контуре. Ванная, кухня, двери и стены не переносятся. К любой планировке можно применить один из пяти вариантов отделки. Фактурные изображения в альбоме показывают настроение материалов, а точные размеры и расположение мебели следует смотреть в плане и 3D-модели.

| План | Главная идея | Что изменено |
| --- | --- | --- |
| D · Лиза | База с проверенными проходами | Исходная расстановка после исправления ванной |
| E · Приём гостей | Общая зона для беседы | Стол, стулья и диван смещены |
| F · Работа у окна | Больше свободного места во второй комнате | Стол и кресло переставлены вдоль боковой стены |
| G · Хранение и порядок | Дополнительный книжный шкаф | Шкаф, кровать и диван переставлены |
| H · Стол поперёк | Другая посадка в кухне-гостиной | Стол повёрнут, стулья перемещены |

План — проектная гипотеза по исходным изображениям. Перед ремонтом нужно обмерить контур, окна, радиаторы, стояки, вентиляцию и проверить возможности перепланировки. Доступность проверяется для условного тела диаметром 500 мм, но это не оценка нормативной доступности и не проверка удобства выбранной мебели.

Идеи: [гибкие зоны и хранение в небольшой квартире (IKEA)](https://www.ikea.com/us/en/ideas/home-furnishings/open-for-adventure-a-studio-apartment-fit-for-a-family-pub64168580/), [прихожая и обеденный модуль в квартире 50 м² (Studio Papaya)](https://www.archdaily.com/1066275/sbc-apartment-studio-papaya), [свет и мебель, объединяющая функции (Segur Flat)](https://www.archdaily.com/1000126/segur-flat-faire). Планировки здесь разработаны под собственную условную геометрию квартиры.

## Локальный запуск

```sh
npm ci
npm run qa
npm run build
npm start
```

Откройте `http://127.0.0.1:4173/` для альбома и `/model.html` для интерактивной модели. Кнопка GLB экспортирует текущую планировку; JSON содержит все пять планировок. `src/data/layout-variations.js` хранит изменения мебели относительно D, а `src/data/layout-reference.json` — геометрию базовой версии. `scripts/variants-qa.mjs` проверяет все пять планов и записывает `variants-qa-results.json`. Браузерная проверка выполняется в GitHub Actions.
