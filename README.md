# Квартира Лизы · одиннадцать вариантов планировки

[Сравнить планы](https://mynameisnastasya.github.io/apartment-master/) · [Открыть в 3D](https://mynameisnastasya.github.io/apartment-master/model.html) · [Базовый план D и размеры](https://mynameisnastasya.github.io/apartment-master/LIZA.html)

**D** — база по исходной идее: кухня слева, ванная по центру, две комнаты у окон и диагональный переход. **E–H** — архитектурные сценарии с разным положением перегородок и дверей. **I–K** — одна компактная гардеробная 2,61 м² в трёх наполнениях: Г-образном, линейном и двухрядном. **L** — предварительная реконструкция нового референса: две спальни у окон, отдельная гардеробная около 3 м² и санузел около 4,53 м². **W4/W6** — семейные сценарии с более крупным хранением. Внешний контур и положение окон сохраняются; вариант L специально помечен как реконструкция по изображению, потому что его размерные подписи не полностью совпадают с условной оболочкой проекта. Пять концепций отделки применяются к любой планировке.

Площади вычислены по **условной геометрии** исходного изображения, не по строительному обмеру. До выбора и ремонта нужны обмер стен, проёмов, окон, радиаторов, стояков, вентиляции и проверка возможности перепланировки, особенно мокрой зоны H и кассетной двери E. Проверка маршрутов использует условное тело диаметром 500 мм; она не заменяет оценку комфорта с реальной мебелью и нормативную проверку доступности.

Интерьерная разработка теперь опирается на отдельное исследование 20 editorial-референсов и самостоятельную концепцию; источники, принципы и критика собраны в [docs/editorial-interior-direction.md](docs/editorial-interior-direction.md). Размеры и решения при этом остаются привязаны к собственному условному контуру квартиры, а не копируют референсы.\n

## Editorial interior direction

Для текущего интерьерного прохода выбран **Walnut Ribbon / Stone Lantern**: тёмный орех работает как единая архитектурная лента, светлый выразительный камень — как один сильный фокус, а бронза, бордо и олива используются дозированно. Кухонный полуостров, ТВ-стена, изголовье и санузел переработаны как bespoke-объекты, а не как набор каталоговой мебели.

Исследование 20 референсов, три разные концепции, аргументация выбора и дизайн-критика собраны в [docs/editorial-interior-direction.md](docs/editorial-interior-direction.md).


## Локальный запуск

```sh
npm ci
npm run qa
npm run build
npm start
```

Откройте `http://127.0.0.1:4173/`. Кнопка GLB экспортирует текущую планировку; JSON содержит все восемь. `src/data/layout-reference.json` — база D; `src/data/layout-variations.js` формирует E–H, подключает гардеробные I–K из `src/data/dressing-layout.js` и вариант L из `src/data/photo-layout.js`: стены, двери, зоны и мебель. `scripts/variants-qa.mjs` проверяет пересечения повёрнутых тел, дверные створки, открывание техники и маршруты; результат — `variants-qa-results.json`. Браузерная проверка выполняется в GitHub Actions.
